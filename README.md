# Memory Game

Игра на поиск пар: откройте 8 пар одинаковых карточек за минимальное количество ходов. В таблице лидеров сохраняются 10 лучших результатов.

## Локальный запуск

Требуется Node.js с npm. В корне проекта выполните:

```sh
npx http-server . -p 8080
```

Если `http-server` ещё не установлен, `npx` предложит загрузить его. Подтвердите запрос, введя `y`.

Откройте [http://localhost:8080](http://localhost:8080).
